Open index.html in a browser to view the site. No TypeScript, React, Node.js, or build step is required.

Files:
- index.html: home page
- portfolio.html: portfolio page with working category filters
- who-we-are.html: studio page
- services.html: services page
- styles.css and script.js: shared styling and small interactive features

The original project references two Lovable-hosted image assets but does not include their image files. This static conversion retains its original “image coming soon” placeholders and uses a stock architectural photograph for the home-page hero.
